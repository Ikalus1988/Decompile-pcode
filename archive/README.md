## 分层约定

- `src/` = KAREL 真源码（ground truth，供 name_map 对拍与还原率度量）
- `pc/` = KTRANS 编译件（LZSS 压缩容器，反编译输入）
- `decompiled/` = pc2kl3 反编译产物（`.KL`）；可读性口径见仓库 `docs/编码表.md`
- `report/` = 最终人读输出（HTML 对照页等）

## 品牌/项目备注

- **JLR**：DCP_* / SPR_* / yamazumi 等 = 捷豹路虎焊装线标准库（CJLR），SPR=自冲铆。
- **饰板线**：XYZ_*（视觉/上下料）、HIK_*（海康相机）、ZJ1000_*、MATRIX = 饰板焊接工位。
- **M9凸点焊**：MM_* = 焊装标准接口库 v1.7.4；MI04_* = 凸点焊 450 工位模块（部署版/MIFAP 两个编译版本）。
- **FANUC**：ISV_VG = iRVision 视觉引导选件（含唯一一份 `.html` 最终对照页）。
