FAP v2.0.9 
MI01 CMN 
1. 自动备份功能逻辑优化，设置的内容不覆盖机器人端口 1 的 IP； 
2. 新增 ProgNumCheck 指令，用于检测程序号；

监控此系列 PRIO 报警， 发生报警后暂停当前机器人动作， 直至报警消失；
相关设置页面位于 MI01 Setup 界面中； 
4. 更新 Decision Code 功能， 加入计时等待， 并将超时时间的设置放入MI01 
Setup 界面中；

台，功能的启停及设备的选择配置位于 MI01 Setup 界面中。

放入后台。
