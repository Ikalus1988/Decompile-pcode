# KAREL p-code 编码速查（.pc 容器）

> 全部经自写探针（probes/）+ 多语料罗塞塔对拍校准；单位/语义以探针为准。

## 容器
- LZSS 流：`FE EF 00 01` + U32BE 声明长（与机器人备份 .pc 同款）
- 头：`00 29 ... <程序名>\0 <版本串>\0 ...`；尾区 = 符号表 + `$GROUP` 映射 + 例程/导入名字表 + 跳转表

## 语句锚点
`3e <行号 u16BE> <偏移 u16BE>` = 5 字节。**行号=主文件 raw 行号**（同版 100% 成立；
dbg_anchor_align 落锤）：`%INCLUDE` 内容只有声明不发锚点；多语句行 `A;B;C` 每语句
一锚点共用行号（重复行号≠假锚点）；锚点单调过滤可剔 `3e` 撞字节假阳性。

## 变量引用（6 字节）
`21/22/23/73/75/9e/9f <01 共享|ff 局部> 00 00 <u16BE 槽号>`
（21=LDi 22=REF 23=STi 73=LDs 75=STs 9e/9f=循环变量；槽号可 >255）

## 参数族（6 字节）
`17/74 <i32BE>`=引用 · `2d <i32BE>`=读 · `2f <i32BE>`=写整 · `a1`/`a2`=读/写串
槽号=负小数（如 `ff ff ff fd`=-3）

## 字面量
- `2e <u32BE>` = 整数（**signed int32**；>2^31 按负数渲）
- `3f <len> <bytes>` = 串（长度无 62 上限，255 以内）
- REAL = IEEE754 位模整数（`0x3a000000-0x4b000000` 窗口）
- `9c`/`9d` = 推 0/1

## 算术/比较（1 字节）
`51`NEG `52`ADD `53`SUB `54`MUL `55`**DIV(整除,KAREL 关键字)** `56`MOD
`69-6c`实型加减乘**除(渲 /)** `57-5c`EQ NE LT LE GT GE `46/47`AND OR `5f`NOT `7d`串拼接
`51`NEG 对字面量渲染 `(0 - N)`（KAREL 表达式一元负号非法）

## 字段/元素
`32 00 <off>` = 字段偏移（合成 `基_f<off>` 独立名）· `33` = 元素地址（`基[下标]`）
`34` = 读字段（恒等）· `35/61` = 写字段/串字段 · `63 <2B>` = UNINIT 布尔谓词

## 控制流
- `79`/`7a <u32BE 跳转号>` = JZ/JMP，**操作数=跳转表索引**（非偏移！）
- 跳转表：`7f 00 00 00 ff 00 <count u16BE> <u32BE 目标>×count`，目标+基址=锚点偏移
- 回边（目标≤当前）→ REPEAT…UNTIL；护栏=头须实语句+区间块自含
- `40/41 <u32>` = SELECT 分派对，`42/43` = 收尾/ELSE

## 调用
`aa 00 <id>`=本模块例程 · `31 00 <id>`=导入 · `76 <id>`=FN 内建 · `27`=实参前缀 · `2a 01`=导入限定
`0x3d` = OPEN FILE（栈=文件变量+参数；ASCII '=' 干扰，元数护栏 ≤6）
`af`/`b0` = GET_VAR/SET_VAR（VGET/VSET，实参扁平 5 参通用形态；`*SYSTEM*` 系统变量
访问含 `1f 00` 串组名——两类形态同一算子）

### FN 内建表（`76 <id>`，编译器全局稳定，fn_census + T_FNS 探针落锤）
`0`=?（内部槽） `1`ACOS `2`ASIN `3`ATAN2 `4`CHR `5`COS `6`CURJPOS `7`CURPOS `8`EXP
`9`=? `10`FRAME `11`INDEX `12`INV `13`IN_RANGE `14`LN `15`ORD `16`POS `17`ROUND `18`SIN
`19`SQRT `20`STR_LEN `21`SUB_STR `22`TAN `23`TRUNC `24`=? `25`CNV_JPOS_REL `26`CNV_REL_JPOS
- id 序≈内建名 **ASCII 序**（1-23 段；`INV(12)<IN_RANGE(13)` 按 `V`<`_` 字节序），25/26=追加段
- **不进本表**：ABS=算子 `50`(整)/`67`(实) 一元、UNINIT=`63`、GET_VAR/SET_VAR=`af/b0`；
  CNV_INT_STR 族/CHECK_*/GET_TSK_INFO 等=CALLIMP（名字表 desc 权威）
- 形参/返回型权威=KAREL 手册 A.x（`STD_SIGS` 注册），过程渲裸调用、函数渲赋值

## WRITE 语句
`ad 32 00 01 <项目>… 2c 01 ff ff`；项目 = `<值> 9c 9c 37 <desc>`，
desc：`1f 00`=串 · `00 10`=整 · `00 d6`=CR

## 符号表（变量真名层）
条目 = `<作用域B> NAME\0 <flags B> <类型 2B> [dims u16BE]`
类型码：`00 10`INT `00 11`REAL `00 12`BOOL `00 1d`FILE `1f <len>`STRING[n] `20 <el>`ARRAY
（元素型同码）`3f ..`ARRAY2D `01 02`POSITION `01 03`JOINTPOS
槽位映射 = `$GROUP\0\xfd` + `0x31xx 标记` + `3×u16 头` + `u16×N`（槽 k+1→符号序，自验证=互异+界内）
**例程局部名不在表内**（编译器剥除）

## 例程/导入名字表
锚点=`<程序名>\0`（前一字节=例程数 u16BE 低位，勿认作字母前缀！）
导入 desc=`<库号> ff ff <ret u16BE> <argc u8> <参数 NAME\0 3B类型>`；例程 desc=`00 <entry u16> …`

## 支持库签名
编译器 `support/*.ev` = PBCORE/REGOPE 权威签名（`NAME\0\xff\xff<argc><ret><参数…>`）；
**basic 支持集≠全量 ev**（robot.ini 缺失只载基础库）——以 KTRANS 裸调用探针实测元数为准
（scripts/probe_bare.py）。
