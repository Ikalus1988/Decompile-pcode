  （版本漂移单列：源码与编译版不同代的部分不计反编译丢失，如 dcp_spot 漂移57）

## 校验口径（validate_sweep.py）
1. 串/常量多重集：dec 语句体区字面量 → 产物 KL 必须全数在场（残差留痕兜底）
2. 真源码保真：min(源码,dec) 的串 → 产物必须在场；源码多出部分=版本漂移单列
3. 回环保真：KL→KTRANS→pc'→dec' 语义指纹对拍
4. 口径剔噪：跳转表 2e 步进伪影、长串内 '?'(0x3f) 子串假候选、数据区(>800B)不计

## 本轮抓到并修复的 bug（迭代史）
1. **静默丢字面量**（表达式链 UNK 操作码挤栈/强转吞串）→ 残差留痕三级兜底
   （语句级 stray/residue + 模块级 module-residue），静默丢失清零
2. **%COMMENT 原注释被覆写** → 从 dec 头还原（`%COMMENT = 'Version 1.0'` 等）
3. looks_real 名字正则槽位偏见（真名 AVX/CALCX 全漏）→ 通用标识符
4. 验证器自身三坑：'?'-串假候选、跳转表假常量、KL 覆盖与回环丢失混算

  操作码精确化）是下一步语义提升点，不影响保真度指标
