## 本轮核心：表达式链装配（续8 遗留的「RT丢」根因）
handoff 记录的「残余 = RT丢（残差注释不进执行码）」经实测**大部分是测量伪影**，
真实残差收敛到**两个代码 bug**，均已修复并逐字验证：

### 1. `is_str` 认不出复合串表达式 → 整段被抹成 `''`
`is_str` 只认「单个串字面量 / 串变量」，嵌套拼接 `('a' + v) + 'b'` 判为非串，
于是 CAT / SET_VAR 实参的类型归一把**整段表达式替换成 `''`**，字面量落进 residue。

- 修复：类型判定改用项目已有谓词 `str_rhs`（携带串语义的表达式），4 处
  （CAT / EQ,NE / CALL 实参 / SET_VAR,GET_VAR 组名与变量名）
- 逐字验证（mm_module）：
  | 修复前 | 修复后 | 真源码 |
  |---|---|---|
  | `v13 = '' + ']'` | `v13 = '$HOSTC_CFG[' + v8 + ']'` | `$HOSTC_CFG[` … `]` |
  | `SET_VAR(v15,'*SYSTEM*','','MM_CLIENT',v16)` | `SET_VAR(v15,'*SYSTEM*', v13 + '.$COMMENT','MM_CLIENT',v16)` | 动态拼接系统变量路径 |

### 2. `32 00 <偏移> 5E` = 串字段访问的 4 字节编码（0x5E 不是转换算子）
旧 tokenizer 只吃 `32 00 <偏移>` 3 字节，把 `5E` 留给 UNK→push `'0'`，串字段被当整数。

- 罗塞塔落锤：`dcpfault_mh.kl:1433`
  `DCPPLCText = RobotName + ',Tool-' + ToolID + ',' + DCPText.DCPLine1 + DCPText.DCPLine2`
  （DCPLine1/2 = 结构体**串字段**）→ token 流 `REF v6 FLD 4 5E CAT`
- 修复：`FLDSTR`（4 字节）+ 合成名进 `str_vars`
- 逐字验证：`v30 = v25 + ',Tool-' + v27 + ',' + v6_f04 + v6_f30` ⟷ 真源码逐字对应

### 3. `off < 0x30` 一刀切误杀首语句
「偏移 < 48 = 头部/数据区」判据把 10 条真语句当元数据丢掉。

- 证据：`dcp_form` `SPRReset` 首句 `SET_PORT_VAL(2,3099,1,STATUS)` 整条丢失（真源码 44 行）
- 修复：改为「无真实语句 token（全 UNK/NOP）才算头部」
- 逐字验证：`SPRReset` 五句全还原，与真源码 44-48 行逐句吻合

## 验证器七坑（本轮抓到 5 个，含自伤 2 个）
| # | 坑 | 症状 | 修法 |
|---|---|---|---|
| 4 | `body>800B=数据区` 布局相关 | 重编译产物语句体更密，真代码被当数据区剔掉（mm_module 12/21 误剔） | RT 对拍改全文件口径 |
| 5 | 子串去重逐文件算 | 两侧字面量环境不同→去重不对称→假丢失 | 对并集对称去重 |
| 6 | `finditer` 非重叠推进 | `3f 3f <len>` 把真长度字节当长度吞 63 字节 | 逐字节滑动+候选校验 |
| 7 | 滑动扫描贪心吃假候选 | `3f 0f` 假候选跳 17 字节吞掉真 `3f 27` 标记 | RT 判据改**字节计数**，不用扫描器抽串做保真 |
| 8 | 残差误报 | `_seg_written` 是 list，`list.count`=元素全等 ≠ `str.count`=子串 → 在场数恒 0 | 传 `' '.join(...)` |
| — | 常量 ASCII 计数 | `count('1000')` 数的是含这四位的**串**，非常量 | 常量定宽无歧义→两侧对称扫 `2e<u32BE>` |
| — | grep 模式写错 | `RT丢串0丢常6` 里没有 `RT丢常` 子串 → "全清"是假的 | 用 `丢串[1-9]\|丢常[1-9]` |

> 教训：**验证器自身要比被测对象更可疑**。本轮 3 次"修好了"其实是换了种方式测错。

## 校验口径（validate_sweep.py，v2）
1. **串/常量覆盖**：dec 语句体区字面量 → 产物 KL 全数在场（残差留痕兜底）
2. **真源码保真**：`min(源码,dec)` 的串 → 产物必须在场；源码多出部分 = 版本漂移单列
3. **RT 回环**：KL→KTRANS→pc'→dec' 保真
   - 串：**原始字节计数**（扫描器有 0x3f 标记歧义，不能做保真判据）
   - 常量：`2e <u32BE>` 定宽 token 两侧对称扫
4. 口径剔噪：跳转表 2e 步进伪影、长串内 '?'(0x3f) 假候选、数据区(>800B)不计
